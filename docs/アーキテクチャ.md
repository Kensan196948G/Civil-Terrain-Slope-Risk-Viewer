# 🏛️ アーキテクチャ

## 🎯 設計原則

- UI、API、データアダプター、分析エンジンを分離する
- 外部障害時は縮退し、`UNKNOWN`を安全扱いしない
- すべての結果に証拠、データ版、アルゴリズム版を結び付ける
- ブラウザからDBへ直接接続しない
- 公開データ取得先はサーバー側allowlistで制御する

## 🧩 コンポーネント

```mermaid
flowchart TB
    WEB["apps/web\nReact + MapLibre"] --> API["apps/api\nCloudflare Workers"]
    API --> DOMAIN["packages/domain\n状態・ルール・証拠"]
    API --> GEO["packages/geo\nDEM・傾斜・断面"]
    API --> ADP["packages/adapters\nGSI等"]
    API --> DATA["packages/db\nNeon"]
    ADP --> PUB["公式公開データ"]
    DATA --> DB[("PostgreSQL")]
```

依存方向は外側から内側へ向け、`domain`と`geo`がCloudflare、React、DBクライアントへ依存しない構成を目標とします。

## 🔄 地点分析シーケンス

```mermaid
sequenceDiagram
    actor U as 利用者
    participant W as Web UI
    participant A as Worker API
    participant C as Cache
    participant G as 公式データ
    participant N as Neon
    U->>W: 地点・半径を指定
    W->>A: POST /analyses/point
    A->>A: 入力検証・上限確認
    A->>C: タイル照会
    alt cache miss
      A->>G: allowlist済みURLで取得
      G-->>A: DEM・地形分類
      A->>C: 規約に従い保存
    end
    A->>A: 正規化・品質・分析
    opt persist=true
      A->>N: 条件・結果・証拠を保存
    end
    A-->>W: COMPLETE / PARTIAL / UNKNOWN
    W-->>U: 地図・カード・根拠
```

## 🧯 縮退方針

| 障害 | 継続できること | 表示 |
| --- | --- | --- |
| DEM停止 | キャッシュ済み表示のみ | 古さと判定不能を明示 |
| 地形分類停止 | DEM由来の分析 | `PARTIAL` |
| Neon停止 | 非保存の一時分析 | 保存不可を明示 |
| 設定破損 | last-known-good | ready=false |
