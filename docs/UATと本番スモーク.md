# UAT計画と本番スモークチェックリスト

## 1. 目的

本番環境 (Cloudflare Access 認証内) で、主要業務フローが期待どおり動作すること、
およびリリース後に運用監視へ引き渡せることを確認する。実施者: 現場技術者代表・
IT・DX部門 (7名体制で継続運用可能な範囲)。

## 2. UATスコープ (v0.2.1)

### 2.1 主要フロー

| #   | フロー       | 操作                                | 期待結果                                       | 受入条件                           |
| --- | ------------ | ----------------------------------- | ---------------------------------------------- | ---------------------------------- |
| U1  | 検索→標高    | 住所または緯度経度で検索            | 地図が移動し、標高・出典・品質が表示される     | 欠損時は「安全を意味しない」が表示 |
| U2  | 地形分析     | 地形タブを開く                      | 傾斜統計・地形分類が実データで表示             | 判定不能時は成功扱いしない         |
| U3  | 断面分析     | 地図で2点指定                       | 縦断プロファイルと勾配統計が表示               | 欠損は補間しない                   |
| U4  | 確認支援     | 確認タブを開く                      | ルール評価カードと推奨確認が表示               | 総合危険度の合算を表示しない       |
| U5  | レポート出力 | 出力タブでMD/CSV/JSONをダウンロード | 出典・判定不能・免責を含むファイルが保存される | CSVに数式注入対策が入る            |
| U6  | 共有URL      | コピー→別ブラウザで開く             | 視点・レイヤーが復元される                     | 機密情報 (住所履歴等) を含まない   |
| U7  | モバイル     | スマホ/タブレットで上記U1〜U6       | 操作可能・タッチターゲット44px                 | 実機2機種以上で確認                |

### 2.2 異常系

| #   | シナリオ                 | 期待結果                                             |
| --- | ------------------------ | ---------------------------------------------------- |
| E1  | DEM取得失敗 (通信遮断等) | 「判定不能」表示・再試行ボタン。安全と誤認しない     |
| E2  | データなし地域           | NO_COVERAGE相当の明示。「安全」としない              |
| E3  | WebGL無効ブラウザ        | 地図のみ縮退表示 (エラーバウンダリ)。他タブは利用可  |
| E4  | アクセス拒否 (未認証)    | Cloudflare Accessログインへ誘導                      |
| E5  | 連続操作 (Rate Limit)    | 429とRetry-After。エッジ/isolate単位の制限として許容 |

### 2.3 セキュリティ確認

- 認証済みユーザーだけが保護ルート (`/elevation`, `/health/ready`) を利用できる
  (JWT検証・RBAC有効化後)
- Workers Logs に座標・メール・トークンが含まれないこと
- 監査イベント (`outcome=denied-role` 等) が requestId で検索できること

## 3. 本番スモークチェックリスト (リリース後・認証セッションで実施)

Access 認証済みブラウザで https://terrain-slope.mirai-dx-platform.com を開き、
以下を確認する (✅ は実施記録欄)。

1. ✅ ログイン後トップが表示され、コンソールエラーが0件
2. ✅ 地図が表示され、国土地理院の帰属が常設表示される
3. ✅ 検索「富士山」で地図移動・標高・出典が表示される
4. ✅ 地形分析タブで傾斜統計と地形分類が表示される
5. ✅ 断面分析で2点指定→プロファイルが表示される
6. ✅ 確認支援でカードと推奨確認が表示される
7. ✅ 出力タブでMD/CSV/JSONがダウンロードでき、内容に出典・免責が含まれる
8. ✅ 共有URLコピー→別タブで復元される
9. ✅ スマホ (1機種以上) で主要操作が可能
10. ✅ `/api/v1/health/live` が200 (Access内)
11. ✅ `/api/v1/health/ready` が503 (DB未接続の正直な表明。Neon接続後に200)
12. ✅ Workers Logs (ダッシュボード) で監査イベントが確認できる
