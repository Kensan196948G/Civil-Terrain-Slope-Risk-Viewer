# ❓ よくある質問と用語集

## よくある質問

### このシステムだけで施工可否を判断できますか？

できません。公開データを使った初期確認支援であり、測量、地質調査、現地踏査、設計計算、行政判断を代替しません。

### 「データなし」は安全という意味ですか？

いいえ。範囲外、欠損、取得障害を含むため `判定不能` です。

### 傾斜30°以上なら危険区域ですか？

この閾値は視覚的な区分・追加確認の契機であり、法令や公式ハザード判定ではありません。

### 現在地は保存されますか？

計画上、明示許可時だけ取得し、`persist=true`を選ばない限り保存しません。

### なぜ公開タイルをCIで直接使わないのですか？

外部変更や停止でCIが不安定になるためです。固定fixtureを必須試験に使い、外部契約試験を分離します。

### 今すぐ起動できますか？

## 用語集

| 用語             | 意味                                        |
| ---------------- | ------------------------------------------- |
| DEM              | Digital Elevation Model。数値標高モデル     |
| GSI              | 国土地理院                                  |
| Horn法           | 3×3近傍から地表面の傾斜を求める方法         |
| EPSG:4326        | 緯度経度で使うWGS 84                        |
| EPSG:3857        | Web地図表示で使うWeb Mercator               |
| `COMPLETE`       | 要求範囲を分析できた状態                    |
| `PARTIAL`        | 一部欠損・一部依存停止がある状態            |
| `UNKNOWN`        | 判断に必要なデータがない状態                |
| Evidence         | 結果を支える出典・取得・加工・版情報        |
| データソース構成 | 分析セルがどのDEM種別から採用されたかの構成 |
| SLI/SLO          | サービス指標と、その目標値                  |
| SSRF             | サーバーを不正な接続先へ誘導する攻撃        |
