# 🚀 開発開始ガイド

## 📌 現在の状態

MVPは実装済みです。`package.json`・monorepo構成(`apps/*`, `packages/*`, `tests/fixtures`)・実行スクリプトがあり、`pnpm install --frozen-lockfile` でセットアップできます。地図UI、単点標高、地形分析、断面分析、確認支援、出力、履歴、初回評価用の架空デモ分析3件をローカルで操作できます。

## 🧱 現在の実装構成

```text
apps/web/                 ✅ React + Vite UI (MVP画面・デモ分析)
apps/api/                 ✅ Cloudflare Workers API (health/elevation/capabilities/sources)
packages/domain/          ✅ 状態・ルール・証拠モデル
packages/geo/             ✅ DEM・傾斜・断面計算
packages/adapters/        ✅ 外部データアダプター
packages/db/              ✅ Neon schema・migration
packages/ui/              ✅ 共有UI
tests/fixtures/            ✅ オフラインのゴールデンデータ
tests/integration/         ⬜ DB永続化系はNeon接続後
tests/e2e/                 ✅ Playwright smoke
openapi/                   ✅ OpenAPI 3.1
```

## 🧰 想定前提

- Node.js >= 22.6.0 (`package.json` の `engines.node` で固定。wrangler 4.x が Node 22+ を要求)、Corepack経由 pnpm 10.26.2
- Git
- CloudflareアカウントとWrangler (apps/apiのdev/deployで使用)
- Neon PostgreSQLの開発ブランチ、またはmock
- 最新2世代のEdge/Chrome/Safari

## ⚙️ 標準コマンド

| コマンド                               | 目的                                 | 状態                           |
| -------------------------------------- | ------------------------------------ | ------------------------------ |
| `pnpm install --frozen-lockfile`       | 依存関係を再現可能に導入             | ✅ 動作確認済み                |
| `pnpm --filter @civil-terrain/web dev` | apps/web のVite開発サーバーを起動    | ✅ 動作確認済み                |
| `pnpm lint`                            | 静的検査                             | ✅ 動作確認済み                |
| `pnpm typecheck`                       | TypeScript strict検査 (fixtures含む) | ✅ 動作確認済み                |
| `pnpm test`                            | 単体試験 (200件)                     | ✅ 動作確認済み                |
| `pnpm format`                          | コードスタイル検査                   | ✅ 動作確認済み                |
| `pnpm build`                           | 全ワークスペースをビルド             | ✅ 動作確認済み                |
| `pnpm test:e2e`                        | E2E試験 (Playwright、地図smoke)      | ✅ 実装済み (CI実行が一次環境) |
| `pnpm --filter @civil-terrain/api dev` | Workers dev (wrangler, port 8787)    | ✅ 実装済み (下記注記)         |

> CI(`.github/workflows/ci.yml`)はGitHub Actions実環境で成功を確認済みです(install/lint/format/typecheck/test/build/Workers bundle dry-run/E2E/dependency audit)。
>
> ⚠️ 注記: Claude Code の自律開発実行環境では headless Chrome と workerd (wrangler dev) がプロセス起動できないため、E2E と Workers 実起動の確認は CI ランナーまたは開発者マシンで行います。Workers 互換性は CI の `wrangler deploy --dry-run` (バンドル検証) で常時ゲートされます。

## 🔐 環境変数

`.env.example`には変数名と説明だけを置き、DB URL、Access JWT、API key等の実値をコミットしません。ブラウザからDBへ直接接続しないでください。
