# 🚀 開発開始ガイド

## 📌 現在の状態

このリポジトリには設計文書のみがあり、`package.json`、アプリケーションコード、環境変数、実行スクリプトはまだありません。したがって、現時点で `npm install` や `npm run dev` は実行できません。

## 🧱 スプリント0で作る基盤

```text
apps/web/                 React + Vite UI
apps/api/                 Cloudflare Workers API
packages/domain/          状態・ルール・証拠モデル
packages/geo/             DEM・傾斜・断面計算
packages/adapters/        外部データアダプター
packages/db/              Neon schema・migration
packages/ui/              共有UI
tests/fixtures/            オフラインのゴールデンデータ
tests/integration/         API・DB・adapter
tests/e2e/                 Playwright
openapi/                   OpenAPI 3.1
```

## 🧰 想定前提

- Node.js LTSとCorepack
- Git
- CloudflareアカウントとWrangler
- Neon PostgreSQLの開発ブランチ、またはmock
- 最新2世代のEdge/Chrome/Safari

実際の最低バージョンは最初のlockfileとCIで固定し、この文書へ反映します。

## ⚙️ 将来の標準コマンド契約

| コマンド候補 | 目的 |
| --- | --- |
| `pnpm install --frozen-lockfile` | 依存関係を再現可能に導入 |
| `pnpm dev` | Web/APIをローカル起動 |
| `pnpm lint` | 静的検査 |
| `pnpm typecheck` | TypeScript strict検査 |
| `pnpm test` | 単体・統合試験 |
| `pnpm test:e2e` | E2E試験 |
| `pnpm build` | 本番ビルド |

> 上記は設計上の契約であり、スプリント0完了まで未実装です。

## 🔐 環境変数

`.env.example`には変数名と説明だけを置き、DB URL、Access JWT、API key等の実値をコミットしません。ブラウザからDBへ直接接続しないでください。

- format、lint、typecheck、test、buildが単一コマンドで再現できる
- Secret scanとdependency auditがCIにある
