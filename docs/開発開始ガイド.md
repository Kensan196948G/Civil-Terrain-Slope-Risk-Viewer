- Node.js >= 20.19.0 (`package.json` の `engines.node` で固定)、Corepack経由 pnpm 10.26.2
- Git
- CloudflareアカウントとWrangler (apps/apiのdev/deploy配線は今後のSprintで追加)
- Neon PostgreSQLの開発ブランチ、またはmock
- 最新2世代のEdge/Chrome/Safari
