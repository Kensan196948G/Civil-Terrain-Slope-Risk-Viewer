# 👤 利用者ガイド

> MVP/Prototype確認用 Web UI (<https://mvp-slope.mirai-dx-platform.com>) の操作を示します。
> 本番URLは <https://terrain-slope.mirai-dx-platform.com> です。
> 本番運用判断ではなく、初期確認・MVP評価のための手順です。

## 🧭 基本操作

```mermaid
flowchart LR
    A["1️⃣ 地点指定"] --> B["2️⃣ レイヤー選択"] --> C["3️⃣ 地形分析"] --> D["4️⃣ 断面分析"] --> E["5️⃣ 確認支援"] --> F["6️⃣ 共有"]
```

1. 地名 (登録済みの目印) または「緯度,経度」の検索、もしくは地図クリックで地点を指定します。指定地点の標高・採用DEM・品質grade・出典が表示されます。
2. 標準地図、写真、陰影起伏、傾斜量などのレイヤーを切り替えます。
3. 「地形分析」タブで、選択地点周辺 (約160m四方) の傾斜統計と地形分類 (尾根・斜面・谷・平坦) をDEM実データから計算します。
4. 「断面分析」タブで、地図上の2点指定による任意線の標高断面と勾配統計を計算します。
5. 「確認支援」タブで、要確認・参考情報・判定不能のカードと、欠損率・採用DEM・出典を確認します。
6. 「出力・共有」タブで、Markdown/CSV/JSONレポートを保存し、表示状態を再現する共有URLをコピーします。検索後は「リセット」で検索前の視点へ戻せます。

## 🧪 デモサンプル

初回起動でも評価できるよう、「履歴」タブに架空のデモ分析を3件同梱しています。
デモは実在地点・実測・個人情報・社内データではなく、比較、確認カード、レポート出力を確認するための合成データです。

1. 「履歴」タブを開きます。
2. 「デモ: 架空ヤードA」「デモ: 架空搬入路B」「デモ: 架空資材置場C」から任意の「開く」を選びます。
3. 地形分析、断面分析、確認支援、出力・共有の各タブで値と注意書きを確認します。
4. 2件にチェックを入れると、項目別比較表が表示されます。

## ⚠️ 結果状態

| 表示        | 意味                             | 次の行動                   |
| ----------- | -------------------------------- | -------------------------- |
| ℹ️ 参考情報 | 公開データから確認できた地形情報 | 必要に応じて詳細調査       |
| ⚠️ 要確認   | 追加確認が必要な観測             | 現地踏査・測量・専門家確認 |
| ❔ 判定不能 | 欠損、範囲外、取得失敗           | 別データや現地で確認       |
| 🟡 PARTIAL  | 一部のみ分析可能                 | 欠損範囲と根拠を確認       |
| 🟢 COMPLETE | 要求範囲の分析完了               | 精度・限界を確認して利用   |

## 📈 断面図の読み方

断面は総延長、サンプル間隔、標高差、累積上昇・下降、平均・最大傾斜を表示します。欠損区間は補間せずグラフを切断します。最大傾斜だけで施工可否を判断しないでください。

## 🧾 共有・引用前チェック

- 対象座標・分析日時が正しい
- 出典、取得日時、採用DEMを確認した
- 欠損率と品質gradeを確認した
- 判定不能・要確認の項目を「安全」と読み替えていない
- 共有URLは視点・レイヤー状態のみを含む (住所、現在地履歴、自由記述は含まれない)
- レポートには加工注記・免責・「データなし/判定不能は安全を意味しない」注意が含まれる
