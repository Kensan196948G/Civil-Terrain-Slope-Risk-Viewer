# 🔌 APIガイド

> Base path: `/api/v1` / 状態: 設計済み・未実装

## 📐 共通契約

- JSON UTF-8、日時はISO 8601 UTC
- 座標はEPSG:4326、APIでは `lon, lat` の順序を固定
- 成功は `{ data, meta }`
- 失敗はRFC 9457相当のProblem Details
- `X-Request-Id`を受信または生成し、応答・ログへ伝播
- UUID/ULIDを公開IDに使用し、連番を公開しない

## 🛣️ エンドポイント

| Method | Path                           | 用途             | 主な制御       |
| ------ | ------------------------------ | ---------------- | -------------- |
| GET    | `/health/live`                 | 生存確認         | 外部依存なし   |
| GET    | `/health/ready`                | DB・設定確認     | 公開制限可     |
| GET    | `/capabilities`                | 利用可能機能     | 公開           |
| GET    | `/sources`                     | 出典・帰属       | 公開           |
| GET    | `/elevation`                   | 単点標高         | Rate limit     |
| POST   | `/analyses/point`              | 地点・周辺分析   | 入力上限       |
| POST   | `/analyses/profile`            | 断面分析         | 最大2,000点    |
| POST   | `/analyses/area`               | 円・ポリゴン分析 | Analyst        |
| GET    | `/analyses/{publicId}`         | 保存結果         | 所有・共有制御 |
| POST   | `/analyses/{publicId}/exports` | 出力             | Rate limit     |
| GET    | `/tiles/proxy/...`             | 許可タイル取得   | allowlist      |

## 📦 地点分析例

```json
{
  "center": { "lat": 35.681236, "lon": 139.767125 },
  "radiusM": 500,
  "layers": ["elevation", "slope", "landform"],
  "slopeBinsDeg": [0, 5, 15, 30, 45, 90],
  "persist": false
}
```

公開デモの半径は50～1,000m、内部上限は2,000mを想定します。NaN、Infinity、異常な指数表記、未知のlayer、過大ポリゴンを拒否します。

## 🚨 エラー

| HTTP | code                        | 意味                         |
| ---: | --------------------------- | ---------------------------- |
|  400 | `INVALID_INPUT`             | 形式・範囲違反               |
|  404 | `NO_COVERAGE`               | データなし。安全を意味しない |
|  409 | `CONFIG_VERSION_CONFLICT`   | 再現条件の不一致             |
|  413 | `ANALYSIS_AREA_TOO_LARGE`   | 上限超過                     |
|  422 | `INSUFFICIENT_DATA`         | 有効データ不足               |
|  429 | `RATE_LIMITED`              | 利用上限                     |
|  502 | `UPSTREAM_INVALID_RESPONSE` | 外部応答異常                 |
|  503 | `UPSTREAM_UNAVAILABLE`      | 外部停止                     |

実装時はOpenAPI 3.1を正本として追加し、この文書との契約差分をCIで検出します。
