# 📄 ライセンスとOSS方針

> 最終更新: 2026-08-12 / 状態: **決定前 (法務・経営判断待ち)** / 現在の package.json: `UNLICENSED`

## 1. 現状

- ソースコード・文書は GitHub (private) が正本。
- 現在は `UNLICENSED` (非公開・著作権留保) のため、外部へ再配布・公開する権利は
  明示されていない。
- 本番公開 (Cloudflare) と社内利用は可能だが、**リポジトリを public 化する前にライセンスを確定**する。

## 2. 選択肢

| 案                       | 内容                       | 向き                  | 注意点                  |
| ------------------------ | -------------------------- | --------------------- | ----------------------- |
| A. 非公開専有 (現状維持) | 社内・契約先のみ利用       | 商用サービス・再販    | OSSコミュニティ貢献なし |
| B. MIT                   | 緩い許諾、帰属表示のみ     | 汎用OSS公開           | 特許・責任条項が薄い    |
| C. Apache-2.0            | 特許付与・貢献者条項あり   | 企業OSS・エコシステム | 表記・NOTICE運用が必要  |
| D. デュアルライセンス    | 社内向け専有 + OSS版を分離 | 公開と収益の両立      | 管理コスト大            |

## 3. 推奨案

**当面は A (非公開専有) を維持**し、外部公開する場合は C (Apache-2.0) を推奨する。
理由:

- 現段階は業務利用者・組織ポリシー・契約が未確定で、公開範囲の決定が先行するべき。
- Apache-2.0 は特許条項を含み、企業が主体となる OSS 公開で一般的。
- データ (国土地理院・国土数値情報等) の帰属・利用条件はコードライセンスと独立して
  管理する必要がある (第4章)。

## 4. データ帰属 (コードライセンスと分離)

| データ                                  | 提供元                                | 扱い                                     |
| --------------------------------------- | ------------------------------------- | ---------------------------------------- |
| 地理院タイル (標高・傾斜・陰影)         | 国土地理院                            | 出典常設表示、利用規約遵守               |
| 重ねるハザードマップ (土砂災害警戒区域) | 国土地理院・国土数値情報 (国土交通省) | 出典常設表示、各都道府県の利用条件も確認 |
| DEM5A 等の標高データ                    | 国土地理院                            | 取得日時・版・品質を画面/レポートへ表示  |

画面・共有・出力に提供元、URL、取得日時、解像度、加工方法、利用規約URLを表示する
既存方針を継続する (要件: 出典表示率100%)。

## 5. 決定手順と完了条件

1. 法務・経営で公開範囲 (private / 取引先限定 / public) と商用利用方針を決定
2. 利用データの規約 (特に都道府県別の土砂災害警戒区域利用条件) を確認
3. LICENSE / NOTICE / CONTRIBUTING を追加し、package.json の `license` を更新
4. SECURITY.md・開発参加ガイドと整合

完了条件: 法務確認済みのライセンス文書がリポジトリに存在し、README・package.json と
一致していること。**それまでは本件を「決定待ち」とし、勝手に public 化しない。**
